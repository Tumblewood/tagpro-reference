Paste Games Import

Adds individual games (with or without EU IDs) to an existing match. Never creates or modifies Seasons, TeamSeasons, Players, or PlayerSeasons — only looks up what already exists. Player stats are taken directly from the JSON. Outcome is inferred from scores (W/L/T only; edit the match afterward if OT is needed).
